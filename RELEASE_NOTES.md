* Phone interface: on touch phones TV Bro now has its own interface, with a bottom bar, a menu, a tab switcher and a home page for small screens. Settings > Interface switches between Auto, TV and Phone
* New TV bar: the address field with a site button, and a tab strip with a menu for each tab (close, close other tabs, move, new tab to the right). The bottom panel is gone
* Ad blocking can be turned on or off for each site, from the site panel
* A loading page can be stopped
* French, Spanish, Portuguese, Greek and Czech translations
* Android 17: TV Bro asks for the permission to access the local network
* Bug fixes: a crash when starting GeckoView on Android 11 and older, running out of memory on pages with huge favicons, a crash of the Version settings tab
